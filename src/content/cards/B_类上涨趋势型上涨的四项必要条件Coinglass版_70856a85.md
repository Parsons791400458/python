# B 类上涨（趋势型上涨）的四项必要条件（Coinglass版）
- 类型：概念
- 可输出性：高
- 标签：[B类上涨, 趋势判定, Coinglass, 价格结构, OI结构, Funding]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6Hv

判定B类趋势上涨必须同时满足四个条件：

1. 价格结构：高点持续抬高，回调不破前低，无15分钟内暴拉暴砸，价格表现为“慢 + 稳 + 丑”。

2. 开仓量（OI）结构：价格上涨但OI不爆炸，回调时OI下降，拉升时OI缓慢上升，表明上涨由现货或长线资金驱动。

3. Funding费率：长期维持-0.01%至+0.02%之间，偶尔转为负但迅速回正，说明市场不完全相信价格仍持续上涨。

4. 爆仓结构：上涨过程中空单被小规模连续爆仓，多单很少大爆，体现慢慢逼空而非踩踏式上涨。

仅符合以上四项的上涨视为真正纯B类上涨。
