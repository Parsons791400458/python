# 底部反弹模型五大信号
- 类型：方法
- 可输出性：高
- 标签：[投资信号, 底部判断, 筹码分析, 情绪指标]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6Hv

判断底部必须等待以下五个信号同时出现：
1. 价格结构“砸过头”，距离高点下跌70%-85%，且跌速放缓。
2. 持仓结OI在低位横盘后放量上涨，价不创新低。
3. 资金费率极端负，多日持续说明市场共识做空形成。
4. 情绪极低，市场怀疑币的未来，没有KOL声音或阴阳怪气。
5. 叙事仍在，项目在生态中有地位，未来6-12个月仍具关注度。

# 低位分批建仓策略
- 类型：方法
- 可输出性：高
- 标签：[投资策略, 建仓, 风控, 底部买入]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6Hv

合理的仓位分配能够降低风险。一种示范分布是：准备资金的30%在0.35买入，30%在0.32买入，20%在0.28极端恐慌价买入，剩余20%留作备用或确认加仓。避免All in单点买入带来的高风险。

# 底部反弹止盈策略
- 类型：方法
- 可输出性：高
- 标签：[止盈策略, 风控, 交易纪律]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6Hv

止盈关键在于及时兑现利润，防止贪婪导致反弹利润回吐。具体操作为：首轮拉升收益达到+30%卖出20%，涨到+50%再卖30%，到前期密集成交区清仓至少50%，剩下的资金作为信仰仓持有。

# 交易模型失效场景
- 类型：概念
- 可输出性：高
- 标签：[风险管理, 模型局限, 失效场景]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6Hv

该底部反弹模型可能失效的情况包括：项目叙事被彻底替代（如旧公链、过时L2、失败GameFi），团队或代币经济结构有毒（无限解锁、频繁砸盘），以及大盘系统性风险（流动性收缩、监管压力).
