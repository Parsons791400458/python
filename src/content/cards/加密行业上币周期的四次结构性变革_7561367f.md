# 加密行业上币周期的四次结构性变革
- 类型：概念
- 可输出性：高
- 标签：[加密行业, 上币周期, 定价权, 结构性变革]
- 来源URL：https://d.biji.com/GvwoYfCDEA1uZ6

加密行业的上币机制经历四个阶段的结构性变革，类比为"牙齿正畸"过程：

1. 乳牙期（社区定价）：定价权掌握在"喊单者"和草根社区，核心路径是直接上币和社区投票。
2. 长牙期（交易所定价）：交易所通过IEO/Launchpad收回定价权，充当"看门人"和"投资银行"，核心路径包括IEO、Launchpad和Launchpool。
3. 畸形期（VC定价崩塌）：一级市场VC定价过高，影响二级市场，交易所介入纠偏，核心路径是HODLer空投和任务分发。
4. 正畸期（市场化/衍生品定价）：定价权由衍生品市场决定，依赖合约交易和盘前定价，核心路径包括币安Alpha空投、盘前交易和钱包集成。

这一演进体现了资产定价权的转移和行业结构的矫正。
